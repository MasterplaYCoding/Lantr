# Third-party notices

Lantr is built on open-source libraries that retain their own licenses and copyright notices. The Gradle and Go lock/configuration files are the source of truth for exact resolved versions.

## Application dependencies

- Kotlin and kotlinx libraries — JetBrains and contributors.
- Compose Multiplatform and Compose resources — JetBrains and contributors.
- AndroidX Activity, Lifecycle, Material, and Navigation components — Android Open Source Project contributors.
- Compose Fluent and Fluent icon extensions — their respective project contributors.
- Krop image cropping UI — its respective project contributors.
- JNA — Java Native Access contributors.

## Director experiment

- Azure SDK for Go and Microsoft Authentication Library for Go — Microsoft and contributors.
- Transitive Go modules retain the licenses recorded by their upstream projects.

## Icons and project media

Material-style drawable icons retain the applicable upstream license. The Lantr app icon and project-specific brand assets are included with the project owner's permission for this archive.

This notice is informational and does not replace the license text distributed by each dependency.

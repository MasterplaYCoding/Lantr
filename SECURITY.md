# Security

Lantr is a source archive rather than an actively supported service. Please report credential exposure, unsafe document parsing, dependency vulnerabilities, or other security-sensitive findings privately through GitHub's security advisory feature instead of opening a public issue.

The editor must remain usable without a network service. Experiments must not bundle credentials and should provide offline test doubles for their external boundaries.

Do not use this archive to process untrusted `.ltrn` files in a security-sensitive environment without reviewing the current archive limits and dependency versions.
